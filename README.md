# Low-Cost Haptic Teleoperation Interface

## Overview

This project explores the development of a low-cost mobile haptic interface
for robotic-hand teleoperation.

The system was designed to improve hand mobility while reducing the mechanical
complexity and cost associated with stationary haptic systems.

## My Contribution

I redesigned, fabricated, assembled, and tested the mobile hardware platform.

My work included:

- PMW3389 optical motion sensor integration
- Arduino Mega 2560 programming
- Continuous X-Y position tracking
- Serial communication between Arduino and Python
- CAD design and 3D printing
- Mechanical prototyping and testing
- Development of a concept for Z-axis finger control

## Technologies

- Arduino Mega 2560
- PMW3389 Optical Sensor
- Python
- C/C++
- Serial Communication
- SolidWorks
- 3D Printing

## System Architecture

User Hand
    ↓
Haptic Interface
    ↓
PMW3389 Sensor
    ↓
Arduino Mega 2560
    ↓
Serial Communication
    ↓
Python / GUI
    ↓
Robotic Control

## Results

The prototype demonstrated continuous X-Y motion tracking while reducing
mechanical complexity compared with the original stationary approach.

The system also established a foundation for future Z-axis and rotational
motion integration.
